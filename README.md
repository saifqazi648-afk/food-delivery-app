# RO45

Operated by BiteRaho

A complete multi-role food and grocery delivery platform with four integrated applications:

- Customer App – browse restaurants and groceries, place orders, track delivery
- Restaurant App – manage menu, process orders, monitor queue
- Delivery Boy App – accept trips, track earnings, receive navigation updates
- Admin Panel – view analytics, control operations, manage vendors and users

## Features

- Customer home feed with restaurant and grocery cards
- Search and category browsing
- Cart and order tracking flow
- Restaurant menu management
- Delivery trip board and earnings dashboard
- Admin analytics and operational controls
- Responsive, modern UI

## Tech Stack

- React 18
- Vite
- Modern CSS

## Run locally

```bash
npm install
npm run dev
```

Open: http://localhost:3000

## Build

```bash
npm run build
```
